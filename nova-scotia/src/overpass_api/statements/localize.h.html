31/* === The statement <em>local</em> ===
32
33The statement <em>local</em> converts the given input into the localized representation of OSM data.
34The output parameter controls which classes of data are included.
35
36Without a type parameter local delivers geometry and tags.
37This is one object per tagged node
38plus one object per part of a way
39plus one object per part of a relation geometry.
40
41With the type parameter "ll", it delivers additionally loose objects.
42There are one object per way with tags but without node members
43and one object per relation member of any relation without node or way members.
44
45With the type parameter "llb", it delivers even more data:
46It delivers the objects that associate the OSM element ids to the aforementioned objects.
47
48The base syntax is
49
50  local <Type>
51
52where <Type> is empty, "ll", or "llb". You can also specify other input and/or output sets than "_":
53
54  .<Set> local <Type> ->.<Set>
55
56The first set is the input set,
57the second set is the output set.
58*/
