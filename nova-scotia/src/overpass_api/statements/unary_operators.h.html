34/* === Unary Operators ===
35
36Unary operators need for execution an operand.
37They are always written in prefix notation.
38The operators can be grouped with parentheses:
39The two variants
40
41  <Operator><Evaluator>
42
43and
44
45  (<Operator><Evaluator>)
46
47have as standalone expressions precisely the same semantics.
48The parenthesis variant exists to override operator precedence.
49
50The order of precedence is as follows, ordered weak to strong binding:
51* logical disjunction
52* logical conjunction
53* equality, inequality
54* less, less-equal, greater, greater-equal
55* plus, binary minus
56* times, divided
57* logical negation
58* unary minus
59
60In the following, the operators are ordered by precedence, stronger binding last.
61*/
