Overpass API: conformance corpus coverage

A conformance corpus is a fixed set of queries that exercises as much of the Overpass API query engine as a large pool of generated queries does, with results that reproduce exactly from run to run, so it can be re-run on every change. Each run below shows, for every source file of the query binary, which lines its corpus runs and which queries run them.
