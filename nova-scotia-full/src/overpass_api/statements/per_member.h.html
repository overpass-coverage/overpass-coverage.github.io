103/* === Per Member Aggregators ===
104
105Aggregators per member help to process information that does apply to only a single member of a way or relation.
106Examples of this are the position within the way or relation, geometric properties like the angles, or roles.
107A per member aggregator needs an element to operate on and executes its argument multiple times,
108passing the possible positions one by one in addition to the element to its argument.
109
110==== Per Member ====
111
112For each element, the aggregator executes its argument once per member of the element.
113The return value is a semicolon separated list of the return values.
114No deduplication or sotring takes place.
115Note that the aggregator returns an empty value for nodes and deriveds
116and does not execute its argument in that case.
117
118The syntax is
119
120  per_member(<Evaluator>)
121*/
