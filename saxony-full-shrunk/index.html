The Saxony full suite with each query shrunk by bench/corpus/reduce.py. Each code path (SanitizerCoverage edge, outside the C++ library) the full suite reaches was given to the first query, in selection order, that reaches it; each query was then cut down (deleting statements, settings, filters, list items and out options) for as long as it still reached the paths it owns and kept its result class (same status, some output if it had output, an out statement, at most 5 CPU seconds). Function argument lists are never deleted, and a set the original query defines stays defined while the query still uses it, so reduced queries keep working on real sets. Queries that own no path, which the full suite kept only for hit counts, were dropped: 692 of 3,110 queries remain, 92% less text in all. Hit counts are not kept.
