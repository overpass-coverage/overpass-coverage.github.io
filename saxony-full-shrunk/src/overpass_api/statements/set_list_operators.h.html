34/* === List Represented Set Operators ===
35
36Sometimes there is a need to represent multiple values in a tag's value.
37Although by no means mandated by the data format,
38the de-facto solution is
39to represent a set of values by a a semi-colon separated list of those values.
40
41This section offers some functions to make handling of these lists easier.
42Currently, the delimiter is hard-coded to a semi-colon.
43For the sake of simplicity,
44leading or trailing white space at each list entry is ignored.
45
46Note also that the lists are understood as sets.
47This means that the order of list elements does no matter.
48*/
