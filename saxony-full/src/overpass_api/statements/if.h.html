30/* === The block statement <em>if</em> ===
31
32''since v0.7.55''
33
34The block statement <em>if</em> executes its substatements
35only if its condition evaluates to boolean true.
36This allows e.g. to try more loosely search conditions
37if stricter search conditions did not deliver a result.
38
39The statement does not directly interact with any sets.
40
41The base syntax is
42
43  if (<Evaluator>)
44  {
45    <List of Substatements>
46  }
47
48resp.
49
50  if (<Evaluator>)
51  {
52    <List of Substatements>
53  }
54  else
55  {
56    <List of Substatements>
57  }
58
59where <Evaluator> is an evaulator and <List of Substatements> is a list of substatements.
60
61*/
