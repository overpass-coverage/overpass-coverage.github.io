30/* === The block statement <em>retro</em> ===

32''since v0.7.55''
33
34The block statement <em>retro</em> executes its substatements
35for the date given in the evaluator.
36
37It is currently undefined
38whether the content of variables from outside the block is available within the block and vice versa.
39Future versions may transfer only derived elements,
40keep the environments completely apart,
41or morph elements from one point in time to the other.
42
43The base syntax is
44
45  retro (<Evaluator>)
46  {
47    <List of Substatements>
