203/* == Evaluators ==
204
205Evaluators are building blocks that yield on execution a value.
206The use of which of the evaluators makes sense depends on the context.
207
208Evaluators help to filter for elements within a query statement.
209They allow to get statistical information about query results.
210And they allow to remove or add tags from elements.
211
212Currently only tag evaluators are supported.
213Geometry evaluators are planned but not implemented in this version.
214
215The following types of evaluators exist and are explained further down:
216* Const evaluators deliver always the same value independent of context.
217* Element dependent evaluators deliver information about an individual object.
218They only make sense in the context of a single element.
219* Statistical evaluators deliver information about a set as a whole.
220* Aggregators let an element dependent evaluator loop over all elements of a set and combine its results.
221* Operators and endomorphisms combine the result of one or two evaluator executions into a new result.
222
223*/
