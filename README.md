# overpass-coverage.github.io

Line coverage of the [Overpass API](https://github.com/fossgis/Overpass-API) query binary
(`osm3s_query`) by fixed regression suites: small sets of queries chosen to exercise as much of
the query engine as a large pool of generated queries does, with reproducible results.

Site: https://overpass-coverage.github.io/

- `index.html`: the list of runs. Add an entry when you add a run.
- `<run>/`, e.g. `nova-scotia/`: one suite on one database, generated by `site.py`:
  - `index.html`: line coverage by directory and file, and the suite's queries.
  - `src/<file>.html`: the source, with each instrumented line marked run or never run; click a
    line's query count for the queries that run it.
  - `q/<n>.html`: one query, its expected status, and the lines only it runs.
  - `corpus.jsonl`: the suite (query text, expected status and output digest).

Each run's pages link back to `../index.html`, so a run must sit one directory below the root.

The runs are generated: don't edit them by hand. The tools are in `bench/corpus/` on the
`corpus-tools` branch of
[cldellow/Overpass-API](https://github.com/cldellow/Overpass-API/tree/corpus-tools/bench/corpus)
(`coverage.py`, `stable.py`, `select.py`, `verify.py`, `linecov.py`, `site.py`; see its README).
For a new run, pass `site.py` `--dataset NAME --out <repo>/<run>`.
