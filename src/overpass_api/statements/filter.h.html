29/* === The Query Filter ===
30
31The query filter can be added as condition to a query statement.
32It has an evaluator as argument
33and it lets pass only those elements for which the expression returns boolean true.
34
35At the moment, the query filter cannot be the only condition in a query.
36This is due to implementation reasons and will change in future versions.
37
38It is technically possible to have multiple query filters in a single query.
39But it does not make sense:
40Their evaulators can be combined with a conjunction in a single query filter.
41This has the same semantics and is faster.
42
43Its syntax is
44
45  (if: <Evaluator>)
46
47The whitespace is optional.
48*/
