34/* === The statement <em>convert</em> ===
35
36The statement <em>convert</em> produces per element in its input set one derived element.
37The content of this output element is controlled by the parameters of the statement.
38
39It is necessary to set a fixed type as type for all the generated elements.
40After that, an arbitrary number of tags can be set.
41In addition, it can be specified to copy all keys from the originating object.
42In this case, it is also possible to selectively suppress some tags.
43
44Finally, it is possible to explicitly set the id of the generated objects.
45If you do not set an id then an unique id from a global ascending counter is assigned.
46
47The base syntax is
48
49  convert <Type> <List of Tags>
50
51where <List of Tags> is a comma separated list of items,
52each of which must be one the following
53
54  <Key> = <Evaluator>
55  ::id = <Evaluator>
56  :: = <Evaluator>
57  !<Key>
58*/
