29/* === The block statement <em>compare</em> ===
30
31''since v0.7.55''
32
33The statement <em>compare</em> computes the diff of the data of two timestamps.
34That diff can consist of any elements as well as only those with specific properties.
35
36The statement can have a block of substatements.
37The block of substatements is executed after computing the diff in the second run,
38once for the old timestamp and then again for the new timestamp.
39This allows to do extra computations based on the diff results.
40
41The statement can only be used in diff mode.
42In other modes its behaviour is undefined,
43and in future versions it might be a syntax error to have it elsewhere.
44
45In the first run of a diff query it returns an empty set.
46In the second run of a diff query it returns the difference of the elements.
47If the statement gets an evaluator as argument
48then only those elements that have different values on both timestamps are returned.
49If the element does not exist on one of the timstamps
50then its value is regarded as the empty string.
51Currently, the only purpose of such a difference is to feed it into an output statement.
52
53The base syntax is
54
55  compare();
56
57In addition, an input and/or output set can be specified:
58
59  .<Set> compare()->.<Set>;
60
61With the evaluator, the syntax becomes
62
63  compare(delta:<Evaluator>);
64
65resp.
66
67  .<Set> compare->.<Set>(delta:<Evaluator>);
68
69In all syntax variants a block of substatements can be attached:
70
71  compare()
72  {
73    <List of Substatements>
74  };
75
76resp.
77
78  .<Set> compare(delta:<Evaluator>)->.<Set>;
79  {
80    <List of Substatements>
81  };
82
83*/
